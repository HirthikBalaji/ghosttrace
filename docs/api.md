# GHOSTTRACE REST API (v1)

Live OpenAPI: `http://localhost:8000/docs` (generated by FastAPI; `tests/test_api.py::test_openapi_matches_docs`
asserts the route list below equals the OpenAPI route list).

**Synthetic demo.** All containment actions are simulations; there is no "executed" state.

## Conventions

- **Auth (demo-only, not production auth):** header `X-GT-Demo-Token: <GT_DEMO_TOKEN>`. If `GT_DEMO_TOKEN` is unset
  the API fails closed with 401. Optional `X-GT-User` (subject label for the audit log).
- **Workspace:** header `X-GT-Workspace` (default `demo`, pattern `^[a-z0-9][a-z0-9_-]{0,40}$`). Each workspace is
  its own FalkorDB graph `ws:<id>`; ids from another workspace return 404.
- **Envelope:** success `{"data": ..., "meta": {"request_id", "synthetic": true}}`; error
  `{"error": {"code", "message", "details"}, "meta": {"request_id"}}`. Codes: `invalid_input` (422),
  `unauthorized` (401), `not_found` (404), `rate_limited` (429), `payload_too_large` (413), `internal_error` (500,
  no stack traces).
- **Time:** query parameters `T` / `tau` / `asof_T` / `known_tau` accept ISO-8601 **with an explicit offset**
  (`2026-03-02T09:00:00Z`) or epoch milliseconds. Naive datetimes are rejected (422). Defaults: the
  investigation's analysis clock (synthetic scenario "now").
- **No endpoint accepts Cypher.** Action ids are validated against `^[a-z_]{3,32}:[A-Za-z0-9_.:@>\-]{1,160}$` and
  then against the deterministic candidate/κ rules. Expensive endpoints are rate-limited per workspace.

## Service

| Endpoint | Purpose |
|---|---|
| `GET /health` | Liveness. No graph dependency. |
| `GET /ready` | Readiness: FalkorDB reachable + schema versions per workspace. 503 when not ready. No secrets. |
| `GET /metrics` | Prometheus-style counters (requests, status classes, latency sum). |

## Scenarios

| Endpoint | Purpose |
|---|---|
| `GET /api/v1/scenarios` | Synthetic scenarios and which one is loaded in this workspace. |
| `POST /api/v1/scenarios/{scenario_id}/reset` | Drop and re-seed the workspace graph from `data/scenarios/<id>.json` (idempotent). |

## Investigations

| Endpoint | Purpose |
|---|---|
| `GET /api/v1/investigations` | List (`limit` ≤ 100). |
| `POST /api/v1/investigations` | Create. Body `{"incident_id"?, "K": 0..3, "policy": "conservative_defense"\|"trust_filtered"}`. |
| `GET /api/v1/investigations/{inv_id}` | Investigation, persisted tasks (state machine) and handoffs. |
| `POST /api/v1/investigations/{inv_id}/run` | Start/resume the agent pipeline (202, background). `?sync=true` runs inline. |
| `GET /api/v1/investigations/{inv_id}/events` | Server-sent events stream (`progress` on every task-state change, then `done`); `max_seconds` ≤ 600. Read with `fetch` streaming because the auth header is required. |
| `POST /api/v1/investigations/{inv_id}/cancel` | Cancel; queued/running tasks become `cancelled`. |
| `GET /api/v1/investigations/{inv_id}/graph` | Snapshot at (`T`, `tau`, `policy`): nodes, active/uncertain edges with class, flags, validity and transaction intervals, sources; `include_inactive` adds edges known but not valid at T; `include_knowledge` adds Company-Brain edges. |
| `GET /api/v1/investigations/{inv_id}/edges/{edge_id}/history` | All bitemporal versions of a fact (supersession chain). |
| `GET /api/v1/investigations/{inv_id}/evidence` | Source records (escaped text) with integrity, trust, attacker-influenceable, roots, injection flag. |
| `GET /api/v1/investigations/{inv_id}/hypotheses` | Investigator hypotheses + evidence-verifier verdicts. |

## Containment and certificates

| Endpoint | Purpose |
|---|---|
| `GET /api/v1/investigations/{inv_id}/containment` | Planner output (Pareto, sensitivity, B0), plans, certificates, red-team findings. |
| `POST /api/v1/investigations/{inv_id}/containment/simulate` | Body `{"action_ids": [...], "T"?, "tau"?, "policy"?}` → a certificate for that action set (`contained` or `not_contained` with residual paths). |
| `GET /api/v1/investigations/{inv_id}/containment/candidates` | Deterministic candidate actions with κ, cost and basis. |
| `GET /api/v1/investigations/{inv_id}/containment/pareto` | Recompute the Price-of-Certainty curve live for (`T`, `tau`, `policy`, `K`). |
| `GET /api/v1/investigations/{inv_id}/certificate/{cid}` | Certificate JSON. |
| `GET /api/v1/investigations/{inv_id}/certificate/{cid}/export` | Canonical snapshot export (JSON Lines) bound by the certificate's hash. |
| `POST /api/v1/investigations/{inv_id}/certificate/{cid}/verify` | Runs `python -m verifier check cert.json edges.jsonl` **as a separate process** and returns exit code and output. |
| `GET /api/v1/investigations/{inv_id}/evidence/load-bearing` | R5 minimal source-record sets whose falsification invalidates each certificate. |
| `GET /api/v1/investigations/{inv_id}/evidence-sensitivity` | R4 diff between `conservative_defense` and `trust_filtered` plans per k. |
| `GET /api/v1/investigations/{inv_id}/report` | Exportable report, `?format=json` (default) or `md`. |

## Company Brain

| Endpoint | Purpose |
|---|---|
| `GET /api/v1/company/owners` | `service_id`, `asof_T`, `known_tau` → owner(s) with source ids, temporal scope, stale/conflict warnings. |
| `GET /api/v1/company/dependencies/{asset_id}` | `direction=dependents\|dependencies`, multi-hop `DEPENDS_ON` with edge ids. |
| `GET /api/v1/company/ask` | `question=owner\|experts\|dependencies\|dependents\|runbooks\|decisions`, `subject_id`. |
| `GET /api/v1/company/search` | Locate entities by name/id substring (locating only; answers come from traversal). |

## Memory and audit

| Endpoint | Purpose |
|---|---|
| `GET /api/v1/memory` | Memory entries with category, provenance, scope, taint, status, freshness. |
| `GET /api/v1/audit/{inv_id}` | Append-only audit events for an investigation (stage starts/completions, tool calls, verifications, simulations). |
| `GET /api/v1/whoami` | Current (demo) principal and workspace; states that auth is demo-only. |
